* Premium

# RESPONSIVE DESIGN

The website must be fully responsive.

### Desktop

Luxury editorial layout with generous spacing and large typography.

### Tablet

Maintain the same visual hierarchy while adapting spacing.

### Mobile

Prioritize a beautiful mobile-first invitation experience.

The opening invitation should fill the entire mobile screen.

Names must remain highly readable.

Buttons must be large enough for comfortable touch interaction.

All sections should transition smoothly without horizontal scrolling.
